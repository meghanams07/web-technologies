Technology Descriptions

  • Java: A high-level, object-oriented programming language used for building applications.
  • HTML: A markup language used to structure web pages.
  • CSS: A stylesheet language used to design and layout web pages.
  • JavaScript: A scripting language used to make web pages interactive.
  • Servlet: A Java technology used to handle web requests and responses on the server side.
  • JDBC: Java Database Connectivity API used to connect and interact with databases.
  • Spring: A Java framework used to build enterprise-level applications.
  • React: A JavaScript library used for building user interfaces.
